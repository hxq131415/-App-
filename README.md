# Resume Template Pro - 20 套可直接对接 OC/HTML 数据交互的简历模板

所有模板都保持一致的数据绑定方式：
- 同样的 DOM id（如 `name`、`job_intent`、`jobs` 等）
- 同样的 `setResumeData(d)`、`renderExperience`、`renderEducation`、`hideIfEmpty` 函数签名
