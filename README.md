# IPA 混淆对比工具

用于对比两个 `.ipa` 包的混淆程度，快速判断混淆是否达到预期。

## 功能

- 自动解压并扫描 `Payload/*.app` 内 Mach-O 文件。
- 提取可见字符串中的标识符并统计：
  - 标识符总数 / 去重数
  - 可读标识符数量（可逆向理解的命名）
  - 随机化标识符数量
  - 平均字符熵
- 输出 `0~100` 的混淆评分并给出结论。

## 使用

```bash
python compare_ipa_obfuscation.py --before before.ipa --after after.ipa
```

## 结果解读

- **可读标识符下降**、**平均熵上升**、**混淆评分上升**，通常说明混淆生效。
- 工具采用启发式规则，建议结合 Hopper/IDA 抽样验证关键类名和方法名。


## 苹果机器审核标准对比（启发式）

工具新增了与苹果机器审核常见静态检查相关的对比项（仅用于风险预警，不代表官方全部规则）：

- 私有 API 命中数
- 越狱检测特征数
- 动态代码特征数（如 `dlopen` / `dlsym`）
- ATS 风险项（`NSAllowsArbitraryLoads=true`）
- 私有 Framework 命中数（`PrivateFrameworks/`）

并输出“审核风险评分(0-100)”，分数越低通常越安全。
